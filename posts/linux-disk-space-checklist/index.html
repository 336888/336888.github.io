Linux 磁盘满了，先查这三处

用 df、du 和 lsof 分清空间用量、inode 耗尽和已删除文件占用。

同样是「磁盘空间不足」，原因可能是数据块用完、inode 用完，或者进程仍持有已删除的文件。先从报错路径入手，确认它实际落在哪个挂载点。

先看挂载点和 inode

df -h /var
df -i /var

把 /var 换成报错目录。如果 IUse% 接近 100%，优先检查产生大量小文件的服务，例如缓存或队列。清理时按服务自身的保留规则操作。

沿同一文件系统往下查

sudo du -x -h --max-depth=1 /var | sort -h

-x 跳过嵌套挂载点。若要核对整个文件系统的占用，把 /var 换成 df 显示的挂载点，再沿最大的目录逐层排查。容器目录占用偏大时，先确认归属和保留策略，再通过容器运行时清理。

df 和 du 差很多时检查打开的文件

sudo lsof -nP +L1

如果发现进程仍持有同一挂载点上的大型已删除文件，确认进程和服务后，按服务支持的方式重开日志文件，或在维护窗口重启服务。处理后重新运行 df -h 和 df -i，确认空间或 inode 已释放。
